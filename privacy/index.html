Privacy and data handling

Last updated: October 9, 2026

Sir Stone Local Transport Relay is a personal-use Mac utility. It uses Google Drive only to transport files encrypted before upload. It accesses the dedicated relay folder's file names, IDs, and ciphertext bytes; it may create that folder. It downloads a selected ciphertext file to the owner's Mac and deletes that Drive file only after local processing and encrypted backup verification succeed. A failed transfer may leave the ciphertext in Drive for retry.

Google's OAuth permission permits broad Drive access so the utility can process files uploaded by a separate sender. During setup, it lists the Drive root to find or create the dedicated folder. Its relay actions then use the configured folder and opaque transport files. OAuth credentials are stored in permission-restricted files on the owner's Mac and are not published with the software.

The utility does not upload plaintext source material to Drive. Decryption and intake occur on the owner's Mac. Its independent off-site recovery copy is encrypted before entering the owner's iCloud Drive. The utility does not sell Google user data or send downloaded Drive file contents to third-party analytics or advertising services.

Removing a transport file from Drive does not guarantee cryptographic erasure from Google's infrastructure. The owner can revoke the OAuth grant in Google Account settings and remove the dedicated relay folder and files in Drive.
