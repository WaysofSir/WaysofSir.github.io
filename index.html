Sir Stone Local Transport Relay

This personal-use Mac utility uses the account owner's Google Drive as a temporary carrier for encrypted files. It downloads an opaque ciphertext file from a dedicated Drive folder, verifies its SHA-256 digest, and processes it locally. After local ingestion and an independently verified encrypted backup succeed, it deletes the transport file from that folder.

The utility requests Google Drive access because it must read files placed by a separate sender and delete them after processing. Its implementation confines relay operations to a locally configured folder and opaque transport filenames. It is not offered as a public service.
